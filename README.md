# homebrew-audionap

Homebrew tap for [AudioNap](https://github.com/IvanTrusenev/audionap) — puts
your Bluetooth speaker to sleep when you are away.

```bash
brew tap ivantrusenev/audionap
brew install --cask audionap
```

AudioNap is ad-hoc signed and not notarized: on the first launch, open
System Settings > Privacy & Security and click "Open Anyway" next to the
AudioNap entry (macOS 15 and later no longer offer the Finder right-click
override). Repeat after every update.
